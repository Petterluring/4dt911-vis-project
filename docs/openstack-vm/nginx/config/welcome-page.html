Welcome to our project.

This is the virtual machine supporting our Visualization Analytics project for course 4DT911. It provides the remote infrastructure needed to run and support the services used throughout our project.

What is this virtual machine?

The virtual machine was created and deployed by our team using LNU’s OpenStack cloud. It serves as the central host for the remote services required by our project, providing a shared and reliable environment where our visualization analytics workflow can run independently of our local machines.

Currently running

At the moment, the virtual machine hosts MLflow, which we use as part of our machine learning and analysis workflow.
